# Maddi Ashrith — portfolio

Static site, no build step. Open `index.html` through any web server (the portrait effect needs http, not file://).

- `css/theme.css` — the cream-and-green classic layer and all project visuals
- `js/main.js` — smooth scroll, engraved portrait lens, contour-map backgrounds, project wheel
- `assets/` — portrait cut-out, photo, favicon
